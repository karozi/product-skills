# Pivot Brief

Template for pivot-catalog Draft mode. Fill every bracket. One pivot, one brief, one
first test.

## What we believed

- **Old hypothesis:** [one falsifiable sentence that has now failed]
- **Triggering evidence:** [cohort facts that killed it — no adjectives, numbers only]
- **Verdict source:** [pivot-or-persevere meeting date and rule that fired]

## What changes

- **Pivot type:** [one of the ten catalog types — exactly one, plus rider if truly
  needed]
- **Why this type:** [one line tying the type to the symptom signature]
- **New hypothesis:** [one falsifiable sentence]

## What survives

- **Preserved learning:** [validated facts that remain true regardless of direction]
- **Assets carried forward:** [users, code, channel knowledge, relationships]
- **What gets discarded:** [explicit list — writing it down prevents relapse]

## The first cheap test

- **MVP type:** [landing page / concierge / Wizard of Oz / piecemeal / single-feature /
  explainer video — see mvp-type-selector]
- **Test design:** [one or two lines]
- **Cost:** [max spend] · **Deadline:** [date]
- **Pass:** [measurable result that confirms the new hypothesis]
- **Kill:** [measurable result that ends this direction — signed before launch]

## Rules

- The first test must produce learning within [N] days. If it cannot, the test is
  wrong, not the timeline.
- One pivot at a time. No simultaneous second pivot until this brief's test completes.
- Re-run pivot-or-persevere on the new direction at the next scheduled review.
