# Pivot-or-Persevere Meeting

Template for pivot-or-persevere Prep and Run modes. 45 minutes, one decision, written
verdict before anyone leaves. Fill every bracket; mark UNKNOWN where evidence is
missing.

## 0. Frame (5 min)

- Current hypothesis under test: [one falsifiable sentence]
- In market since: [date] · Decision window committed to: [window]
- This meeting decides: [PERSEVERE / PIVOT / PERSEVERE WITH THRESHOLD]

## 1. Evidence (15 min — read aloud, no interpretation yet)

- Baseline at start: [metric values when this direction began]
- Cohort trend: [cohort table — activation, retention, conversion, revenue per cohort]
- Learning log: [validated learnings this window, each tied to a completed experiment]
- Engine of growth: [sticky / viral / paid] — health: [churn trend / viral coefficient
  trend / LTV:CAC trend]

Missing evidence gets named here, not papered over.

## 2. Rule check (10 min)

- Persevere conditions met: [which of the four, with the cohort fact for each]
- Pivot conditions met: [which of the five, with the cohort fact for each]
- Inadmissible evidence heard and struck: [sunk cost, cumulative charts, vibes — logged]

## 3. Verdict (10 min)

Only three outcomes are legal:

- **PERSEVERE** — all four persevere conditions hold; named next experiment: [experiment]
- **PIVOT** — pivot condition [n] triggered; new hypothesis: [one falsifiable sentence];
  first cheap test: [one line]
- **PERSEVERE WITH THRESHOLD** — tripwire: [metric] below/above [value] by [date]
  forces [forced action]. All four tripwire elements present or the extension is void.

## 4. Sign and schedule (5 min)

- Written verdict: [recorded by whom, where]
- Next review date: [date — even a PERSEVERE gets a scheduled next look]
- If PIVOT: owner of the pivot test plan: [name] · due: [date]

## Rules of order

- Evidence section happens before opinions. No exceptions.
- Anyone can call "sunk cost" on an argument; the chair strikes it and moves on.
- The verdict is written before the meeting ends. A decision that exists only in the
  room did not happen.
