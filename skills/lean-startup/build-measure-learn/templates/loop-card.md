# Loop Card

Template for build-measure-learn Plan mode. One loop, one card. Fill every bracket
before building anything.

## Learn (define first)

- **We believe:** [action] will cause [measurable outcome] because [mechanism]
- **The learning this loop exists to produce:** [the question the loop answers]
- **If we are wrong, the direction that dies is:** [what a failed threshold costs]

## Experiment (smallest that teaches)

- **Form:** [smoke test / MVP type / feature change / analysis — see
  smoke-test-launcher and mvp-type-selector before building anything]
- **Why this is the smallest form:** [one line — what was cut]
- **One variable:** [the single thing that changes]

## Measure (defined before build)

- **Metric:** [the number the loop moves]
- **Baseline:** [current value — measure it BEFORE building]
- **Threshold:** [value that confirms the belief]
- **Kill:** [value that refutes it]
- **Sample / duration needed:** [N users or time for the number to mean anything]
- **Date:** [when the verdict is read]

## Build (minimum)

- **What gets built:** [one line]
- **What deliberately does not:** [the cut list — the longer, the better the loop]

## After (closing the loop)

- **Believed before:** [hypothesis, restated]
- **Measured:** [metric vs threshold]
- **Now we believe:** [one falsifiable sentence]
- **Outcome:** [LEARNED (confirmed/refuted) / INCONCLUSIVE (fix: ...) / WASTED
  (cause: ...)]
- **Next loop:** [one line — spawned by this learning, not by the old roadmap
  position]

## Rules

- The card opens with Learn, not Build. A card that starts with Build goes back.
- Timebox: [date]. Two overruns close the loop as failed.
- The measure exists before the build or the loop does not start.
